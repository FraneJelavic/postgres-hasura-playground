# Support

This project is community-maintained on a best-effort basis. It provides no uptime,
response-time, compatibility, data-recovery, or production support guarantees.

Before requesting help:

1. Confirm the host meets the [compatibility matrix](docs/compatibility.md).
2. Run `make status` and retain its complete output.
3. Review [Operations](docs/operations.md) and recent Compose logs.
4. Reproduce with the default configuration and disposable data when possible.

For a public issue, include the host operating system and architecture, Docker,
Compose, and Colima versions, the command run, complete error output, relevant
sanitized logs, and minimal reproduction steps. Never post secrets, personal data,
or private infrastructure details.

Questions about designing or operating a real highly available database platform,
data recovery, security hardening, and production capacity are outside this
playground's support scope. Consult the upstream projects and qualified operators.

Report suspected vulnerabilities privately as described in
[SECURITY.md](SECURITY.md).
